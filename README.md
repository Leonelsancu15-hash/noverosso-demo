# NoveRosso — Redesign-Demo (Akquise)

Anteprima di redesign non ufficiale per NoveRosso Restaurant, Via Giuseppe Casaregis 9R, Genova.
Sito attuale: https://www.noverosso.it

- `index.html` — pagina completa (CSS e JS inline), `privacy.html` — bozza informativa
- Tutte le foto provengono dalla mediateca di noverosso.it (convertite in WebP)
- Font (Bodoni Moda, Instrument Sans) e librerie (GSAP 3.12.5, ScrollTrigger, Lenis 1.1.18) locali, nessuna CDN
- Menù trascritto dal PDF `NEW_MENU_NOVEROSSO.pdf` (luglio 2026)
- `noindex`: la demo non deve comparire nei motori di ricerca
- Il modulo di prenotazione è in modalità demo e non invia nulla

Pubblicazione: file tutti nella radice (niente sottocartelle), quindi caricabili con “Upload files” su GitHub.
